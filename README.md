# SpendWise – AI-Powered Personal Finance Coach

SpendWise is an AI-powered personal finance web application that helps users manage expenses, build healthier financial habits, and make smarter financial decisions through personalized insights and intelligent recommendations.

The application combines expense tracking, AI-generated financial advice, savings planning, budgeting tools, and visual analytics into a single easy-to-use platform.

---

## Features

### Expense Management
- Add, edit, and delete transactions
- Automatic expense categorization
- Income and expense tracking
- Transaction history
- Monthly spending overview

### AI Financial Assistant
- Personalized financial recommendations
- Smart saving suggestions
- Budget optimization tips
- Spending behavior analysis
- "What-If" scenario analysis for financial planning

### Budget & Savings
- Goal-based savings tracker
- Emergency fund estimation
- Adaptive planning for irregular income
- Budget monitoring
- Savings progress visualization

### Financial Insights
- Interactive spending charts
- Category-wise expense breakdown
- Monthly financial reports
- Spending trend analysis
- AI-generated financial summaries

### Gamification
- Savings streaks
- Achievement badges
- Financial milestones
- Micro-learning modules for financial literacy

## Installation

### Clone the repository

```bash
git clone https://github.com/yourusername/SpendWise.git

cd SpendWise
```

---

## Install Dependencies

```bash
npm install
```

---

## Configure Environment Variables

Create a `.env` file in the root directory.

Example:

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

AI_API_KEY=your_api_key
```

---

## Run the Project

Start the backend

```bash
npm start
```

or

```bash
npm run dev
```

Frontend (if separate)

```bash
cd frontend

npm install

npm run dev
```

Backend:

```
http://localhost:5000
```

Frontend:

```
http://localhost:3000
```
